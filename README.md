# Simple Interest Calculator

A simple Bash script project designed to calculate simple interest based on user inputs.

## Project Description
This project is part of the IBM Getting Started with Git and GitHub course final project. It contains a script that computes simple interest given principal, annual rate of interest, and time period in years.

## Output:
Given:
- **p**: Principal amount
- **t**: Time period in years
- **r**: Annual rate of interest

```text
Simple Interest = (p * t * r) / 100
